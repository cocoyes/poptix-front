# 海外二手票交易与 Ticket Pool 平台

## 项目立项及产品功能说明 V1.0

---

# 1. 项目概述

## 1.1 项目定位

本项目面向中国大陆以外的演唱会、音乐节、体育赛事、电竞赛事及其他现场活动，建设一个融合：

* 海外二手票交易
* Ticket Pool 随机购票
* 买卖报价与价格发现
* 门票即时流动性
* Stablecoin 支付
* 法币充值
* Web3 钱包
* 用户积分激励

的一体化票务资产交易平台。

平台不是传统意义上的“黄牛票商城”，也不是单纯的 Web3 NFT Ticket 项目。

核心定位为：

> **Ticket Liquidity Marketplace**
>
> 面向真实门票资产的交易、价格发现和流动性平台。

普通用户可以直接买票，也可以通过 Ticket Pool 以固定价格随机获得真实门票。

专业卖家可以正常挂售门票，也可以将库存组成 Ticket Pool，提高库存周转效率。

用户获得门票后，可以：

* 持有
* 挂售
* 接受当前市场报价立即卖出
* 等待价格变化
* 最终领取真实门票

平台自身原则上不作为门票做市主体，不承诺固定价格回购，而是通过买家、专业交易商和流动性提供者的报价形成市场流动性。

# 2. 产品核心逻辑

整个产品围绕以下闭环建设：

```text
真实门票
   ↓
验证真实性
   ↓
映射为平台 Ticket Asset
   ↓
归属具体活动 / 场次 / 官方票档
   ↓
────────────────────
↓                  ↓
Marketplace        Ticket Pool
直接交易            随机购买
↓                  ↓
用户持有 Ticket Asset
   ↓
─────────────────────────────
↓            ↓             ↓
Sell Now     List          Redeem
接受报价      挂单出售       领取真实门票
↓            ↓
Order Book / Marketplace
   ↓
新的持有人
```

门票可以在正式交割前多次进行所有权转移。

# 11. Balance 状态

资金不能只设计一个余额字段。

至少分为：

### Available

可用于：

* Draw
* 买票
* 出价
* 提现

### Locked

已经用于：

* Bid
* 未完成订单
* Ticket Pool Draw
* 争议交易

### Pending

已经产生收入，但尚未满足最终结算条件。

主要针对：

* 卖家销售收入
* 高风险卖家
* 尚未完成票据最终交付的交易

# 31. Cash-out 机制

所谓“折现”不是平台固定回收。

而是：

> 用户在有效期内可以根据市场 Bid 选择即时出售。

例如：

用户今天抽到 VIP1：

Best Bid：

> $760

用户可以卖。

两天以后：

Best Bid：

> $850

也可以继续卖。

如果：

> 没有 Bid

则 Sell Now 不可用。

用户仍然可以挂 Ask。

因此平台不承担兜底责任。

# 37. Points 基本原则

第一阶段 Points：

* 不可购买
* 不可出售
* 不可转账
* 不可提现
* 不直接等同 Token
* 不承诺固定兑换比例

未来如果平台发行 Token：

可以考虑：

> Points Snapshot

作为 Token 分配、等级、权益或活动资格的重要参考。

不建议早期直接宣传：

> 1 Point = X Token

这样既限制未来 Tokenomics，也会明显增加监管和用户预期风险。

---

# 38. 买家积分

行为：

### Buy

购买门票获得积分。

### Draw

参与 Ticket Pool 获得积分。

### Place Bid

真实有效报价获得积分。

但不能简单按“挂单次数”奖励，否则容易刷量。

可以根据：

> Bid 距离市场价格的距离

决定奖励。

例如：

非常接近 Best Bid：

奖励更高。

---

# 39. 卖家积分

卖家行为：

### Listing

提供真实门票。

### Sale

成功成交。

### Pool

向 Ticket Pool 提供库存。

### Liquidity

愿意接受合理市场价格。

### Successful Delivery

门票最终成功交付。

其中：

**Successful Delivery**

建议给予较高积分。

鼓励真实优质票源，而不是鼓励纯刷交易量。

# 45. Seller Settlement

Seller 成交以后：

收入可以先进入：

> Pending Balance。

根据风险等级决定结算速度。

例如：

### Trusted Seller

较快释放资金。

### New Seller

部分资金保留。

### High Risk Seller

更高比例 Reserve。

这样可以防止：

卖家拿钱跑路，而活动数周以后用户才发现票无效。

# 47. 合规设计

这一部分建议从项目第一天就预留。

因为平台同时涉及：

* Stablecoin
* 法币
* 二手票
* 随机商品
* 用户余额
* 跨境支付

不同国家可能分别涉及：

* KYC
* AML
* VASP
* Money Transmission
* Stored Value
* Ticket Resale
* Gambling / Lottery
* Consumer Protection

等监管。

FATF 当前要求受监管的虚拟资产服务商采取客户尽职调查、记录保存、可疑交易报告等措施，并涉及 Travel Rule；2026 年 FATF 仍在持续强化稳定币和跨境虚拟资产监管。

例如美国 FinCEN 对“接受并向另一方传输可兑换虚拟货币”的业务存在 Money Transmitter 判断，因此产品不能简单因为使用 USDC 就默认属于普通电商支付。

因此建议：

> 支付、On-ramp、Off-ramp、KYC 和部分 Crypto Compliance 尽可能使用持牌第三方。

平台把重点放在票务交易本身。

# 48. Randomness

Ticket Pool 的开奖结果必须：

* 不可被 Seller 修改
* 不可被平台运营人员修改
* 用户可以验证

后续可以采用：

> VRF（Verifiable Random Function，可验证随机函数）

或者：

> Commit-Reveal

等机制。

即使第一阶段暂时不上链：

也必须保存完整抽取日志及随机种子证明。

# 58. 项目真正的护城河

长期来看，项目真正有价值的不是：

> Web3。

也不是：

> 抽卡。

而是四项基础设施。

### 1. Ticket Supply

大量真实专业票商库存。

### 2. Ticket Standardization

不同官方售票平台的票被统一映射为：

> Event → Session → Ticket Class → Ticket Asset。

### 3. Price Discovery

拥有：

> Bid + Ask + Last + Volume

形成真实市场价格。

### 4. Liquidity

用户获得 Ticket Asset 后：

> 可以快速再次出售。

共同组成整个 Ticket Economy。

# 60. 一句话项目定义

> **一个面向全球现场娱乐市场的二手票资产交易平台，通过标准化票档、市场报价和 Ticket Pool 随机购票机制，为真实门票提供价格发现、交易和即时流动性。**
